## 1. DANH SÁCH LỖI PHÁT HIỆN

### 🔴 MỨC CAO (HIGH)

#### [HIGH-01] Magic String thay vì Enum trong `FeedbackType` — `food.service.ts`
- **File:** `my-web/backend/src/modules/food/food.service.ts` dòng 149, 152
- **Nội dung vi phạm:**
  ```typescript
  // ❌ SAI
  feedbackType: 'LIKE',
  ```
- **Nguyên nhân:** Vi phạm trực tiếp `prisma-rule.md` — cấm dùng string literal cho Enum field. Prisma đã định nghĩa `FeedbackType { LIKE, DISLIKE }`.
- **Tác động:** Nếu tên Enum thay đổi trong schema, lỗi sẽ chỉ xuất hiện tại **runtime**, không bị TypeScript bắt tại compile time.
- **Giải pháp:**
  ```typescript
  import { FeedbackType } from '@prisma/client';
  feedbackType: FeedbackType.LIKE,  // ✅ ĐÚNG
  ```

---

#### [HIGH-02] Magic String thay vì Enum trong `StaffInvitationStatus` — `restaurant.service.ts`
- **File:** `my-web/backend/src/modules/food/restaurant.service.ts`
- **Dòng vi phạm:** 329, 340, 343, 390, 397, 615, 636, 651, 674
- **Nội dung vi phạm:**
  ```typescript
  // ❌ SAI — xuất hiện ở nhiều nơi
  status: 'PENDING'
  status: 'REVOKED'
  status: 'ACCEPTED'
  status: 'DECLINED'
  ```
- **Nguyên nhân:** `StaffInvitationStatus` đã được định nghĩa đầy đủ trong `schema.prisma` (PENDING, ACCEPTED, DECLINED, REVOKED) nhưng toàn bộ service dùng string thay vì import Enum.
- **Giải pháp:**
  ```typescript
  import { StaffInvitationStatus } from '@prisma/client';
  status: StaffInvitationStatus.PENDING  // ✅ ĐÚNG
  ```

#### [HIGH-03] Magic String cho Role trong `restaurant.service.ts`
- **File:** `my-web/backend/src/modules/food/restaurant.service.ts` dòng 434
- **Nội dung vi phạm:**
  ```typescript
  role: 'STAFF',  // ❌ SAI
  ```
- **Giải pháp:** Sử dụng `UserRole.STAFF` đã import từ `@prisma/client`.

#### [HIGH-04] Magic String cho `UserStatus` mapping trong `restaurant.service.ts`
- **File:** `my-web/backend/src/modules/food/restaurant.service.ts` dòng 305, 460, 474
- **Nội dung vi phạm:**
  ```typescript
  // ❌ SAI — mapping thủ công bằng string
  status: staff.status === 'APPROVED' ? 'ACTIVE' : 'INACTIVE',
  updateData.status = dto.status === 'ACTIVE' ? 'APPROVED' : 'REJECTED';
  ```
- **Tác động:** Đặc biệt nguy hiểm vì ánh xạ 2 chiều (`APPROVED ↔ ACTIVE`) mà không có kiểm soát kiểu dữ liệu.
- **Giải pháp:**
  ```typescript
  import { UserStatus } from '@prisma/client';
  status: staff.status === UserStatus.APPROVED ? 'ACTIVE' : 'INACTIVE',
  ```

## 4. ĐIỂM TÍCH CỰC (STRENGTHS)

- ✅ **Zero SQL Injection** — toàn bộ query qua Prisma ORM type-safe.
- ✅ **Auth bảo mật xuất sắc** — JWT HttpOnly Cookie, bcrypt Refresh Token, brute-force protection, CSRF Guard.
- ✅ **CORS chuẩn** — Dev linh hoạt, production chặt chẽ.
- ✅ **XSS được xử lý** — DOMPurify, XssSanitizerInterceptor global, Helmet headers.
- ✅ **Ownership Check đầy đủ** — Không có IDOR trong UPDATE/DELETE.
- ✅ **AI Prompt Safety** — Input được trim, đưa qua structured prompt.
- ✅ **SafeImage chuẩn** — Whitelist domain, fallback `onError`.
- ✅ **Next.js không dùng wildcard hostname** — Đã whitelist cụ thể 5 domain.
- ✅ **Constants tập trung tốt** — `limits.constant.ts`, `messages.constant.ts`, `ai.constant.ts`.
- ✅ **Frontend API layer chuẩn** — Toàn bộ qua `apiClient`, không fetch trực tiếp trong component.
- ✅ **AI Architecture ấn tượng** — 10+ sub-services phân tách rõ ràng.
